# 最后一条消息 (The Last Message) - 模块 A「110 报警电话」

本项目为叙事解谜游戏《最后一条消息》的**模块 A「110 报警电话」**完整实现。严格遵循《模块A「110报警电话」综合美术需求》文档标准构建。

---

## 体验与设计亮点

1. **4:3 CRT 真实硬件拟真**
   - 严格 4:3 构图视口，外围自然融入 2010 年代中国派出所值班室暗夜环境。
   - 真实 CRT 扫描线 (Scanlines)、暗角 (Vignette)、微枕形失真、荧光粉余晖微光 (`phosphor glow`) 与环境漫反射。
   - 幕 2 采用高还原度 CRT 开机动画（中心水平亮线展开 + 消磁抖动），直接唤醒接警登记单。
2. **纯正 2010 Windows XP 警务客户端**
   - 原汁原味 XP Classic 灰色直角控件（凸起/凹陷斜面按钮、凹陷输入框、原生下拉框）。
   - 装饰性智能 ABC 浮动输入法条。
   - 单号、接警时间、电话、报警人系统锁定只读；事发地址特殊灰显；警情内容自由打字（慢节拍光标）。
   - 警情分类严格 4 项（咨询类 / 误拨 / 无法核实 / 其他），选“咨询类”自动关联带出“无实质警情”。
3. **沉浸式程序化音效 (Procedural Web Audio)**
   - 无需外挂庞大音频资源，纯代码算法实时合成：老电话震铃、摘机按键、挂机忙音、CRT 消磁开机电流啸叫与微弱工频嗡鸣、老键盘阻尼敲击声、待机时钟跳秒声。
4. **全流程 8 幕自动化与交互状态机**
   - **幕 0**：黑屏来电（~4s，呼吸感微光纯黑，自动响铃接听）
   - **幕 1**：通话（~47s，居中偏下字幕缓慢渗出，无头像无对话框，右上角录音中红点缓闪）
   - **幕 2**：挂断与开机转场（~6-8s，忙音静置后 CRT 硬件亮线撑开）
   - **幕 3**：接警单（核心交互，提交后全单定格变灰只读）
   - **幕 4**：待机大屏跳秒（~7s，夜态黑底琥珀点阵时钟真实跳秒 → 无声反色硬切为昼态米白底深灰字）
   - **幕 5**：死亡通报（XP 模态公文排版弹窗，关闭按钮置灰锁定）
   - **幕 6**：系统追问（延迟 1.8s 追加系统日志灰字）
   - **幕 7**：出现场（XP 凸起按钮，全屏唯一点选）
   - **幕 8**：标题落版（~9s，画面缓慢均匀压暗至黑场，《最后一条消息》大号白字浮现与档案编号）

## 运行方式

无需复杂构建环境，直接使用任何本地 Web 服务器即可体验：

### 方式 1：使用 Python 简易服务
```bash
python -m http.server 8080
```
然后在浏览器中打开 `http://localhost:8080`。

### 方式 2：使用 Node.js / npx
```bash
npx serve .
```
